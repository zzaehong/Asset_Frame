# 배당수익률 (`dividend_yield`)

- 분류: 투자운용결과분석
- 상태: implemented
- 구현: `src/asset_frame/analytics/dividend.py` — `trailing_dividend_yield`
- 테스트: `tests/test_dividend.py`, `tests/test_dashboard.py`

## 정의

최근 12개월 동안 받은 주당 분배금 합계를 기준일 종가로 나눈 값이다. 이미 낸 배당이지 앞으로의 배당이 아니다.

## 공식

배당수익률 = Σ 분배금(기준일 − 12개월 < 배당락일 ≤ 기준일) ÷ 기준일 종가(raw)

- 분배금: Tiingo `divCash`, 배당락일 기준, 그날 주식 수 단위의 달러 금액
- 종가: 분할 조정하지 않은 `close`. 기준일은 자산별 마지막 거래일이다.

## 구현상의 선택

- 기준일 이후 액면분할이 있으면 그 이전 분배금을 분할 비율로 나눠 현재 주식 수 단위로 맞춘다(2025-12-05 2:1 분할 5종).
- 같은 배당락일이 여러 snapshot에서 중복 저장돼도 한 번만 센다.
- 가격 이력이 12개월보다 짧거나 종가가 0 이하면 값을 만들지 않는다(화면에 표시 없음). 12개월 동안 분배금이 없으면 0으로 두고 "배당 없음"이라 표시한다.
- 계산은 `Decimal`, 반올림하지 않는다. 화면은 소수 첫째 자리 %.
- 결과에 `calc_version`(`dividend_yield_v1`)과 기준일을 붙인다.

## 한계

- 세전 값이다. 세금·환율은 반영하지 않는다(USD).
- 특별배당과 정기배당을 구분하지 않아, 일시적으로 큰 분배금은 수익률을 키운다.
- 수익률 계산(총수익 지수)은 배당 재투자를 이미 반영한다. 이 값은 표시용 정보이며 백테스트 입력이 아니다.
