## 정의

일간 가격에서 계산하는 추세·모멘텀·과열 지표다. 계산 버전 `indicators_v1`.

## 공식

- SMA(n) = 최근 n개 값의 평균. 이동평균선은 20·60·120·240일.
- EMA(n): α = 2 / (n + 1), 처음 n개의 SMA로 시작.
- RSI(14): Wilder 평활(α = 1/14), 처음 14개 변화의 평균으로 시작. 상승·하락이 모두 0이면 50.
- MACD = EMA(12) − EMA(26), 시그널 = MACD의 EMA(9), 히스토그램 = MACD − 시그널.
- 스토캐스틱(14, 3, 3, 슬로): 원시 %K = 100 × (종가 − 14일 최저가) / (14일 최고가 − 최저가), 범위가 0이면 50. %K = 원시 %K의 SMA(3), %D = %K의 SMA(3).
- 거래량 비율 = 오늘 거래량 / 최근 20일(오늘 포함) 평균.

## 구현상의 선택

- 가격 기준은 총수익 지수(조정 종가를 한 snapshot 안에서 이어 붙인 값, `total_return_index` 카드)다. 고가·저가는 (총수익 지수 ÷ 원시 종가)를 곱해 보정한 값이고 화면에 "보정값"이라고 쓴다. 거래량은 원시 값.
- 지표는 전체 이력으로 계산하고 화면에는 최근 504거래일만 싣는다. 가격은 첫 표시일을 100으로 맞춘다.
- 이력이 모자라면 None이다(앞쪽 값을 채우지 않는다).
- 기간별 수익률(히트맵)은 거래일 21·63·126·252일 전 대비 총수익률로 1·3·6·12개월 근사다.
- 계산은 `float`이다(지표는 비교·표시용이며 회계 값이 아니다).

## 한계
