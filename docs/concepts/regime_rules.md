# 경기 국면 규칙 (`regime_rules`)

- 분류: 거시경제분석
- 상태: implemented
- 구현: `src/asset_frame/regime/rules.py`(순수 함수), `regime/replay.py`(월말 replay·채점), `regime/jobs.py`
- 데이터: [macro_first_release](macro_first_release.md)의 최초 발표값 + 월간 수익률(SPY·IEF)
- 실행: `asset-frame regime` → `var/reports/regime_replay.csv`와 콘솔 채점
- 테스트: `tests/test_regime_rules.py`, `tests/test_regime_replay.py`
- 계산 버전: `regime_v1`

> 침체 규칙은 산업생산·실업률·CFNAI 같은 **실물경제 지표**로 경기 침체를 판단한다. 주식시장 하락장(bear market)과는 다른 개념이며, 화면에는 "실물경제 침체 신호"로 표시한다.

## 규칙 (결과를 보기 전에 정했고, 시도 횟수는 규칙당 1회)

판단 시점은 월말이며 그날까지 발표된 값만 쓴다.

| 규칙 | 정의 |
|---|---|
| Sahm 지표 | UNRATE 최신 3개월 평균 − 직전 12개월의 3개월 평균 중 최솟값(%p). 입력 월이 하나라도 없으면 계산하지 않는다 |
| `indpro_sahm` | INDPRO 전년비 < 0 **그리고** Sahm ≥ 0.5%p → 침체 |
| `cfnai_sahm` | CFNAI-MA3 < −0.70 **그리고** Sahm ≥ 0.5%p → 침체 |
| L3 4분면 | 성장: CFNAI-MA3 ≥ 0이면 up. 물가: CPI 전년비가 3개월 전 전년비보다 높으면 up |
| 상관 국면 | 직전 36개월 SPY–IEF 상관 > 0이면 `stock_bond_positive`(채권이 주식을 헤지하지 못함) |

- 임계값 0.5%p는 Sahm의 원 정의다. −0.70은 시카고 연준의 문구("확장 뒤 CFNAI-MA3가 −0.70 아래면 침체 가능성 증가")이며 침체 기준선으로 공식 선언된 값은 아니다.
- "그리고"(두 신호 모두)는 오탐을 줄이려는 사전 선택이다. 하나만 켜져도 침체로 보는 변형은 시도하지 않았다.

## 채점

USREC(NBER, 침체 후 정점~저점 더미)과 같은 달의 규칙 값을 비교한다. **보조 진단일 뿐 규칙 채택 기준이 아니다.** NBER은 수개월~1년 이상 뒤에 확정되는 사후 기록이라 판단 시점에는 알 수 없고, 일치도가 높아도 투자 성과가 좋다는 뜻이 아니다. 규칙의 주 평가는 신호에 따른 포트폴리오의 CAGR·최대낙폭·샤프(벤치마크 대비), 원장에 기록한 신호의 사후 채점, 독립 표본 수다(M6-1부터 적용). 대시보드는 NBER을 표시하지 않는다. 기록: 채점한 달 수, NBER 침체 달 수 중 탐지, 침체가 아닌 달의 경보(오탐), 에피소드별 첫 경보까지 걸린 달 수.

## 한계

- 표본이 적다. 2007년 이후 NBER 침체는 2007-12~2009-06, 2020-03~04 두 번뿐이고 `cfnai_sahm`은 최초 발표 이력이 2011-06부터라 2020년 하나만 채점한다. 규칙 우열을 가릴 수 없다.
- **발표 지연이 구조적 지연을 만든다.** 4월 실업률은 5월에 발표되므로 4월 말 판단에는 3월까지만 보인다. 2020년은 침체 기간이 2개월뿐이라 침체 중에는 경보가 없고 5월에 켜져 오탐으로 집계된다. 판단 시점을 달리하거나 지연 허용 채점은 아직 정하지 않았다.
- **침체가 끝난 뒤에도 Sahm이 남는다.** 2009-07~2010-02(8개월)가 오탐으로 집계된다.
- **결측이 규칙을 막는다.** 2025-10 실업률은 발표되지 않아(결측 NULL) 이후 15개월 동안 Sahm이 계산되지 않는다. 임의로 메우지 않았다.
- UNRATE 최초 발표값으로 만든 Sahm은 FRED의 SAHMREALTIME(개정 반영)과 값이 약간 다를 수 있다.
