# 평균-분산(최소분산 포트폴리오) (`mean_variance`)

- 분류: 분산투자기법
- 상태: implemented
- 구현: `src/asset_frame/analytics/allocation.py` — `minimum_variance_weights`
- 테스트: `tests/test_allocation.py`
- 사용: `min_variance` 전략(`config/strategies.toml`)

## 정의

기대수익률은 추정하지 않고, 공분산만으로 포트폴리오 분산이 가장 작은 비중을 고른다. 평균-분산 효율적 경계의 가장 왼쪽 점이다.

## 공식

min wᵀΣw, 조건 Σw = 1, 0 ≤ w_i ≤ 상한. Σ = 36개월 표본 공분산(ddof=1)

## 구현상의 선택

- 롱온리, 레버리지 없음. 자산당 상한은 `max_weight = 0.30`이다. 이 값은 PRD에 정해져 있지 않아 임의로 정했고 민감도 분석 대상이다.
- 상한 × 자산 수가 1보다 작아 불가능하면 상한을 1/n으로 올린다.
- 풀이는 표준 라이브러리로 구현한 쌍 단위 갱신이다. 한계 분산이 가장 큰 자산에서 가장 작은 자산으로 비중을 옮기고, 그 직선 위에서 정확한 최솟값 걸음을 쓴다. 수렴하지 않으면 오류를 낸다. 닫힌 해(자산 2개)와 격자 탐색으로 검증했다.
- 현금(BIL)이 앵커에 들어 있어 변동성이 매우 낮은 현금·단기채에 비중이 몰린다. 이는 계산 오류가 아니라 최소분산의 성질이다.

## 교재와 다른 점

- 교재의 평균-분산은 기대수익률을 함께 쓴다. 기대수익률 추정 오차가 크므로 여기서는 쓰지 않는다.
- 추정 오차: 36개월에 자산 12개이면 공분산 추정이 불안정하다. `--window-months`로 24·60개월과 비교한다.
