# 예측과 채점 (`prediction_scoring`)

- 분류: 투자운용결과분석
- 상태: implemented
- 구현: `src/asset_frame/prediction/models.py`(모델), `scoring.py`(순수 채점 함수), `jobs.py`(원장 기록·채점·성적표)
- 실행: `asset-frame ledger predict-models | predict | score | scoreboard`
- 테스트: `tests/test_prediction.py`
- 계산 버전: `prediction_v1`

## 질문

월말 t에 두 가지를 예측한다. ① 12개 1단계 앵커의 t 이후 3개월 누적 수익률 순위(좋을 것 같은 순서) ② t+3개월 시점의 SPY–IEF 직전 36개월 상관이 양수일 확률. 월간 수익률 파이프라인(SPY 달력)에 맞춰 63거래일 대신 월간 3개월을 쓴다.

## 모델

| 모델 | 순위 | 상관 확률 |
|---|---|---|
| `momentum_12_1` | t 직전 11개월(t 제외) 누적 수익률 내림차순. 11개월이 다 없는 자산은 제외 | 지금 상관이 양수면 1.0, 아니면 0.0(지속 예측, 조정 모수 없음) |
| `equal_rank` | 날짜로 시드를 고정한 무작위 순서(기준선) | 0.5 |
| `human` | 사용자가 입력(최소 6개 티커, 근거 한 줄) | 사용자가 입력 |

## 채점 (3개월이 지난 뒤)

- **순위 IC:** 예측 순서와 실현 수익률의 Spearman 상관(동률은 평균 순위). 실현값이 있는 자산이 6개 미만이면 계산하지 않는다.
- **상·하위 스프레드:** 예측 상위 3개의 평균 실현 수익률 − 하위 3개의 평균.
- **Brier:** (확률 − 실현 부호)². 실현 부호는 t+3개월 시점 36개월 상관이 0보다 큰지.
- **성적표:** 모델별 채점 건수, 평균 IC, 평균 스프레드, 평균 Brier, IC의 최소 탐지 효과(MDE = 2.8 × 표준편차 / √n, 5건 미만이면 표시하지 않음).

## 한계

- 매달 예측하면 3개월 구간이 겹쳐 독립 표본 수는 건수의 약 1/3이다. MDE는 그만큼 낙관적이다.
- 한 번 채점해서는 우열을 알 수 없다. 첫 채점은 2027-01 판단 후에 나온다.
- 지속 예측의 1.0/0.0은 Brier를 가장 가혹하게 만든다. 확률을 조정하면 시도 횟수가 늘어난다.
- 순위는 앵커 12개 사이의 상대 순위이며 절대 수익률 예측이 아니다. 비용·세금은 반영하지 않는다.
