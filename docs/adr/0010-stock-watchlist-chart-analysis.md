# ADR-0010: 개별 주식을 차트 분석 전용 관찰 목록으로 허용하고, ETF 차트는 배분 보조 정보로 바꾼다

- 상태: 채택
- 날짜: 2026-11-22
- 관련: PRD 3절·5.3절, [ADR-0002](0002-tiingo-eod-price-basis.md) 가격 기준, [ADR-0008](0008-mac-app-read-only.md), `chart_signal` 개념 카드

## 배경

ETF 31개에 차트 지표와 투표 규칙(`chart_signal_v2`)을 적용해 봤다. 분산된 ETF는 추세가 약하고 지표 투표가 서로 상쇄해 매수·매도 판단이 모호했다(31개 중 16개가 중립, SPY의 "매도 우위" 뒤 3개월 평균이 +2.9%). 사용자는 차트 분석을 개별 주식에 쓰고 ETF는 다른 방향으로 쓰기를 원한다(2026-11-22). 그러나 PRD 3절은 "개별 주식 선택"을 비목표로 두었다.

## 결정

1. **범위.** 사용자가 직접 고른 미국 상장 주식 최대 50종목을 "차트 분석 전용 관찰 목록"으로 허용한다. 종목 추천·자동 선정, 기본적 분석(재무·밸류에이션), 주문, 미국 외 주식은 계속 제외한다.
2. **종목 선택.** 도구는 추적 중인 ETF의 큰 보유 종목 후보 목록(`config/stock_candidates.toml`)을 보여 주고, 사용자가 고른 결과만 `config/stocks.toml`에 기록한다. 후보 목록은 사용자 확인용이며 자동 수집하지 않는다(AGENTS 3절). 보유 비중은 수시로 바뀌어 후보 목록의 값은 근사다.
3. **분리.** 개별주는 `asset_type = stock`으로 별도 목록에 두고, 전략·백테스트·실험실·위험 분석·원장 예측·월간 수익률 빌드는 ETF 유니버스만 읽는다. 앵커 ETF 시계열은 바뀌지 않는다(PRD 4절 7항).
4. **수집.** 승인된 공급원 Tiingo의 기존 수집기를 쓴다. Starter 한도(월 500종목, 시간당 50요청)에 맞춰 종목 수를 50개로 제한하고 75초 간격을 유지한다. 분할·배당은 기존 가격 기준(ADR-0002)과 `corporate_actions`로 처리한다.
5. **분석.** 개별주에는 4단계 판단(추세 방향 → 추세 강도 → 과열·타이밍 → 거래량 확인)을 적용한다. 규칙은 구현 전에 개념 카드에 확정하고 사용자가 승인한다. 신호별 과거 성과와 독립 표본 수를 함께 표시하며, 수익률이 높다는 이유로 규칙을 고르지 않는다.
6. **ETF.** 매수·매도 판정 문구를 빼고 배분 보조 정보(추세 필터, 상대강도 순위, 낙폭·변동성 경고)를 표시한다. 기존 캔들·지표 차트는 유지한다. 규칙은 같은 방식으로 확정·승인한다.
7. **원장.** 개별주 판단을 원장에 기록할지는 사용자 승인 뒤 별도로 정한다.

## 결과와 한계

- **생존 편향:** 지금 시점에 고른 종목이라 과거에 상장폐지됐거나 부진했던 종목이 빠져, 과거 성과 통계가 좋아 보일 수 있다. 화면에 표시한다.
- **표본:** 종목 수가 적고 종목마다 신호 횟수가 적다. 독립 표본이 5 미만이면 해석하지 않는다.
- **수집 시간:** 50종목이면 약 2시간이 든다(요청 2회×75초). 이번 달 한도(500종목)에서 ETF·대용 펀드 약 45종목을 이미 썼다.
- 기술적 지표가 개별주의 미래 수익을 예측한다는 근거는 강하지 않다. 이 변경은 판단을 설명 가능하게 만드는 것이며 수익을 약속하지 않는다.
