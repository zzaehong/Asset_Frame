# ADR-0005: 가설 원장 중심 설계

- 상태: 채택
- 날짜: 2026-11-18
- 대체: ADR-0004(재검토 중이던 제품 목표 부분). ADR-0004의 코드 정리, SQLite 전환, 데이터 원칙은 PRD 4절로 승계한다.

## 맥락

ADR-0004의 "거시 국면 기반 포트폴리오 생성"은 검증되지 않은 신호로 비중을 정하는 구조였다. 사용자 인터뷰(2026-11-18)에서 정한 1순위 성공 기준은 수익률이 아니었다. "국면별 예측과 실제 결과를 검증 가능한 데이터로 축적하는 것"이었다.

실증 연구도 이 방향을 뒷받침한다. Stangl·Jacobsen·Visaltanachoti(2009)와 Molchanov·Stangl의 연구는 경기 국면을 완벽히 미리 안다고 가정해도 섹터 로테이션의 초과수익이 작다고 보고했다. 그래서 통념을 그대로 운용 규칙으로 쓰지 않고, 검증 대상으로 둔다.

## 결정

1. 제품의 중심은 **추가 전용(append-only) 가설 원장**이다. 순위 예측을 사전 등록하고 63거래일 후에 채점한다.
2. 국면은 달리오 프레임을 3층으로 분해한다. L1 장기 맥락, L2 경기 4단계, L3 성장×물가다. 원장의 기본 단위는 L2다. Big Cycle은 수십 년 단위로 움직여서 월간 원장의 단위로 쓸 수 없다.
3. 순위는 여러 모델이 같은 인터페이스로 경쟁해서 만든다. 모멘텀 기준선을 반드시 포함한다. 사용자 예측도 같은 규칙으로 채점한다.
4. 원장은 해시 체인으로 변조를 감지한다. replay(유사 표본 외)와 live(표본 외)는 분리해서 보고한다.
5. 포트폴리오 층은 원장에서 신호가 검증된 뒤(M5)에 만든다.
6. 투자자산운용사 학습 내용은 개념 레지스트리로 관리하고, 필요한 층에서 그때그때 끌어온다(pull).
7. 화면은 정적 HTML로 시작하고, 이후 같은 SQLite를 읽는 SwiftUI 앱으로 전환한다.

## 결과

- 첫 결과물은 투자 비중이 아니라 "모델별·국면별 성적표"다.
- ETF 실제 이력만 쓰기 때문에 침체 표본이 세 번뿐이다. 그래서 국면별 결론은 잠정적이다.
- 규칙과 모델을 바꾸면 버전이 늘어나고, 시도 횟수도 함께 늘어난다. 늘어난 시도 횟수는 이후 Deflated Sharpe Ratio 평가에 반영한다.
- ADR-0004는 "ADR-0005에 의해 대체됨"으로 표시한다.
