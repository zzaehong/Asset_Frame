# ADR-0004: 거시 국면 기반 포트폴리오 도구로 피벗

- 상태: [ADR-0005](0005-hypothesis-ledger.md)에 의해 대체됨 (2026-11-18)
  - 대체된 부분: "결정"의 제품 목표(거시 국면 기반 포트폴리오 생성)와 새 원칙(목표 비중·리밸런싱
    제안 출력), 과최적화 방지 항목. 제품의 중심은 ADR-0005의 추가 전용 가설 원장으로 바뀌었다.
  - 계속 유효한 부분: 코드 정리, SQLite 전환(ADR-0001 부분 대체), ADR-0003 대체. "유지하는
    원칙"의 데이터 원칙(공식 원천, 결정론적 계산, point-in-time, 충돌 격리, 자동매매 없음)은
    [PRD](../../PRD.md) 4절로 승계되었다.
  - 이력: 2026-11-18 오전에 "재검토 중"으로 표시한 뒤 같은 날 ADR-0005로 대체했다.
- 날짜: 2026-11-17

## 맥락

v0.1은 데이터 계보 인프라(SEC·OpenDART·GDELT·유니버스 배치·PostgreSQL·대시보드)를 약 1.18만
줄 쌓았지만 분석 코드는 한 줄도 없었다. README는 리스크 엔진을 "구현됨"으로 적었지만 어느
브랜치에도 해당 코드가 없었다. 수집 범위(870개 유니버스, 공시·재무·뉴스)가 실제 사용처보다
앞서 커졌고, "판단은 사용자 몫"이라는 원칙 때문에 제품이 내놓을 출력이 정의되지 않았다.

## 결정

제품 목표를 다음으로 바꾼다.

- 세계 거시경제(성장·물가·신용·유동성)를 읽고, 그 결과로 개인 포트폴리오를 생성·리밸런싱·
  재구성하는 개인용 도구를 만든다. 사용자는 1명(저장소 소유자)이다.
- 투자 대상은 미국 상장 ETF와 한국 상장 ETF 합계 10~20개다.
- 마켓 타이밍은 "언제 오를지 예측"이 아니라 "국면 인식 → 위험 노출 조절"(추세추종·변동성
  타기팅)로 정의한다.

### 폐기하는 원칙

- 기존 README·PRD·AGENTS.md의 "매수·매도 점수 금지 / 목표 비중을 내지 않음 / 판단은 사용자
  몫" 원칙. 이 원칙은 ADR 파일이 아니라 README·PRD·AGENTS.md에 있던 내용이다.
- ADR-0003(근거 기반 870개 분석 유니버스). 유니버스는 ETF 10~20개로 줄인다.
- ADR-0001 중 PostgreSQL을 canonical 저장소로 쓴다는 결정. 단일 사용자·소규모 유니버스에는
  표준 라이브러리 `sqlite3`로 충분하므로 SQLite로 바꾸고, Docker Compose·마이그레이션 도구를
  제거한다.

### 새 원칙

- 시스템은 목표 비중과 리밸런싱 제안을 출력할 수 있다.
- 모든 출력에는 근거 지표, 데이터 기준시점, 계산 버전, 백테스트상 한계를 붙인다.
- 실제 주문은 사용자가 한다. 자동매매와 주문 권한은 없다.

### 유지하는 원칙

- 공식 원천만 사용한다. 비공식 금융 데이터 라이브러리와 크롤링·스크래핑을 금지한다.
- 숫자는 결정론적 코드로 계산한다.
- point-in-time: 가격은 같은 (자산, 거래일, 공급원)이 다시 수집되어도 덮어쓰지 않고 새
  버전을 추가한다. 거시 지표는 ALFRED vintage를 사용할 예정이다.
- 데이터 충돌은 평균하지 않고 격리(`quarantined`)한다.
- ADR-0001의 원본 보존·SHA-256 계보·격리·프로토콜 경계 결정과 ADR-0002의 Tiingo 가격 기준.

## 결과

- 삭제: SEC·OpenDART·GDELT 커넥터, 유니버스·배치·보존 정책, PostgreSQL adapter와 스키마,
  FastAPI 대시보드, 의존성 `fastapi`·`uvicorn`·`psycopg`. 코드는 git 이력에 남는다.
- 유지: Tiingo·KRX 가격 수집, raw store, 가격 품질 검사, Source Registry, SQLite repository.
- 공급원은 Tiingo, KRX(available)와 FRED, ECOS(planned) 4개만 둔다.
- 목표 비중을 출력하므로 과최적화 위험이 커진다. 백테스트 시도 횟수를 기록하고 Deflated
  Sharpe Ratio로 평가하는 것을 PRD의 필수 원칙으로 둔다.
