# ADR-0009: 대용 펀드로 자산 이력을 늘리고, 긴 기간은 별도 보기로 둔다

- 상태: 채택
- 날짜: 2026-11-21
- 관련: [ADR-0002](0002-tiingo-eod-price-basis.md) 가격 기준, [ADR-0008](0008-mac-app-read-only.md), 현금 대용(DTB3)

## 배경

침체 에피소드가 2007~2009, 2020 두 번뿐이라 국면별 과거 성과의 독립 표본이 너무 적다. ETF는 상장 전 이력이 없고(SPY 1993, 채권 2002, 하이일드 2007 등), CFNAI 최초 발표 이력은 2011-05에 시작한다. 반면 INDPRO(1927~)·UNRATE(1960~)·CPIAUCSL(1972~)의 최초 발표 이력은 길고, 같은 시장을 추종하는 오래된 인덱스·채권 펀드는 Tiingo(승인된 공급원)에 있다.

## 결정

1. **대용 펀드 이어 붙이기.** `config/proxies.toml`에 대상 ETF마다 대용 펀드 하나와 등급을 둔다(`index` 같은 지수 / `close` 비슷한 시장 / `rough` 사용자가 알고 고른 거친 대용). 대용 월은 대상의 첫 수익률 달 **이전에만** 쓰고 항상 대용으로 표시한다.
2. **사용 기준은 결과를 보기 전에 고정.** 겹치는 구간(대상 상장 후)이 36개월 이상이고 월수익률 상관이 등급 기준(`index` 0.97, `close` 0.90, `rough` 제한 없음) 이상일 때만 쓴다. 미달이면 쓰지 않고 이유를 기록한다. 금은 사용자 결정(2026-11-21)으로 금광주 펀드(FSAGX)를 `rough`로 쓴다.
3. **분리 저장.** 대용 월은 `proxy_return`, 겹침 검사는 `proxy_check` 테이블에 둔다. 기존 `monthly_return`과 모든 기존 분석(백테스트·위험·실험실)은 **실제 ETF 이력만** 계속 읽는다.
4. **대용이 없는 자산**(은·원자재·섹터·스타일·SCHD 등)은 확장하지 않고 상장 이후만 쓴다.
5. **긴 기간은 별도 보기.** 대시보드의 "긴 기간 보기"를 켜면 시장 국면·국면별 과거 성과가 1962년부터, 대용 포함 수익률로 나온다. 기본은 실제 ETF만(2007~)이다.
6. **성장×물가 4분면 병행.** 기존 CFNAI 기준(2011-06~)은 그대로 두고, 산업생산·CPI 기준(`quadrant_ip`, `regime_ip_v1`, 1973~)을 별도 규칙으로 추가한다. 성장은 INDPRO 전년비가 직전 120개월 평균 이상이면 up, 물가 방향은 기존과 같다. 시도 1회.
7. 달러지수는 `DTWEXM`(주요통화, 1973~2019)을 `DTWEXBGS`(2006~)의 겹치는 첫 60개 관측 비율로 보정해 앞쪽에 연결한다.

## 결과와 한계

- 대용 펀드는 보수·구성·만기가 ETF와 달라 추적 오차가 있다. 검사 결과(상관, 연 추적 차이)는 `build-returns` 출력과 화면에 표시한다.
- 1970~80년대는 금리 수준과 시장 구조가 지금과 달라서 과거 반응이 반복된다는 보장은 약하다. 긴 기간 결과를 기본 결과와 합치지 않고 별도 보기로 둔 이유다.
- 전략 비교와 실험실의 공통 기간은 늘지 않는다(은·원자재 등 대용 없는 자산이 전략에 들어 있다).
- 원장(ADR-0007)의 기존 항목과 `regime_v2` 정의는 바뀌지 않는다. 긴 replay는 원장에 기록하지 않는다.
