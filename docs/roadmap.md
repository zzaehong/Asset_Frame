마일스톤의 완료 조건은 [PRD](../PRD.md) 9절이다. 이 문서는 진행 상태, 세부 단계, 결정 대기와 M2 이후 상세를 둔다. 병합이 끝날 때마다 갱신한다(로드맵 아티팩트는 2026-11-21에 사용자가 삭제했고 더 쓰지 않는다). 마일스톤은 날짜가 아니라 완료 조건으로 정한다.

## 3. 결정 기록

- `var/` 백업(2026-11-19): 위치는 저장소 밖 `~/Backups/Asset_Frame`(`BACKUP_PATH`), `asset-frame backup`으로 수동 실행한다. 같은 디스크라 디스크 고장은 막지 못하므로 외장 디스크나 클라우드 동기화 폴더로 `BACKUP_PATH`를 바꾸는 것을 권장한다. 주기는 수집 직후 실행한다.
- `min_variance` 상한 민감도(2026-11-19): 20·40% 변형을 전략으로 추가했다. 월간 리밸런싱·198개월 기준 상한 20/30/40%는 샤프 0.561/0.536/0.529, 최대낙폭 −9.0%/−5.8%/−3.6%, CAGR 3.2%/2.6%/2.1%다. 상한이 높을수록 현금 비중이 커져 수익과 변동성이 함께 줄어든다. 30%를 유지한다.
- 현금은 다른 자산과 같은 하나의 자산이다(2026-11-19). 전략·위험 분석·대시보드에서 현금을 빼지 않고, 현금을 뺀 변형 전략은 만들지 않는다. `inv_vol`·`erc`가 현금에 73~84%를 두는 것은 이 결정에 따른 결과로 두고, 대시보드의 "현금 비중"과 평균 비중 막대로 드러낸다.
- 규칙 평가 기준(2026-11-21): NBER 일치도는 보조 진단이며 규칙 채택 기준이 아니다. 대시보드에서 NBER 표시를 제거했다(코드·`USREC` 수집·원장 필드는 유지, 원장은 수정 불가). 규칙의 주 평가는 ① 신호에 따른 포트폴리오와 벤치마크의 CAGR·최대낙폭·샤프, ② 원장에 기록한 월말 신호의 사후 채점, ③ 독립 표본 수 표시다. 높은 수익률만을 기준으로 규칙을 고르지 않는다(AGENTS 10절).

## 3.1 M2 준비 계획

PRD 9절의 M2를 "한 작업에 새 계층 하나" 규칙으로 나눈다. 코드는 아래 결정을 받은 뒤 시작한다.

| 단계 | 내용 | 새로 필요한 것 |
|---|---|---|
| M2-1 | 거시 데이터 층: FRED/ALFRED 시리즈를 vintage와 함께 수집(`macro_observation`은 이미 있음) | `SUPPORTED_SERIES` 확장, 시리즈별 개념 카드(단위·발표 지연·개정) |
| M2-2 | 국면 규칙: L2 두 규칙 경쟁(INDPRO+Sahm / CFNAI-MA3+Sahm), L3 성장×물가, 상관 국면. 2007년~ replay로 NBER 침체와 일치도 기록 | 순수 함수 분석 층, 임계값, 개념 카드 |
| M2-3 | 해시 체인 원장: 추가 전용 항목, 예측 등록, 해시 검증 | ADR-0005 구현, 새 테이블 |
| M2-4 | 사용자 예측과 채점: 63거래일 후 자동 채점, 오차 노트 | 채점 규칙, 대시보드 탭 |

| vintage | 처음엔 ALFRED 최초 발표값만 replay에 사용 | 개정 누수 방지, 구현 최소 |
| 침체 정답 | USREC(NBER) | 공식 날짜, 발표가 늦어 replay 보조 진단에만 사용(화면 표시 없음) |
| Sahm 결측 처리 | 3개월 중 2개월이 있으면 있는 달만 평균(2025-10 결측 대응). 결측 한 달만 건너뛰는 예외라 과거 결과는 변하지 않는다 | 지금은 엄격하게 결측이면 계산하지 않아 현재 국면 판단이 비어 있다. 값을 메우는 일이라 승인이 필요하다 |
| 판단 지연 | 채점을 "침체 시작 후 N개월 안 탐지"로 바꾸고 N을 사전 고정 | 발표 지연 때문에 월말 같은 달 채점은 구조적으로 늦다 |
| 원장 저장 | SQLite 테이블 + 이전 항목 해시 열(ADR-0007로 구현) | 새 의존성 없음 |

**M2-1에서 확인한 제약:** 최초 발표 이력이 CFNAIMA3는 2011-05부터라, "CFNAI-MA3 + Sahm" 규칙의 2007~2011 replay는 point-in-time이 아니다(개정값 혼입). "INDPRO + Sahm" 규칙은 1960년대부터 point-in-time이다. M2-2는 개정값을 쓰지 않고 그 전 달의 `cfnai_sahm`을 계산하지 않는다(채점 대상에서 빠진다).

**M2-2 replay 결과(월말 판단, NBER 대비):** `indpro_sahm`은 채점 227개월 중 NBER 침체 20개월 가운데 13개월을 탐지했고 오탐 22개월이다(2008 침체는 5개월 뒤 경보, 2020은 발표 지연 때문에 침체 중 경보 없음). `cfnai_sahm`은 174개월 중 침체 2개월, 탐지 0, 오탐 3개월이다. 침체 에피소드가 2~3개뿐이라 규칙 우열은 판단할 수 없다. 2025-10 실업률 결측은 `regime_v2`(3개월 중 2개월 평균)로 처리해 과거 결과는 그대로이고 현재 판독이 채워졌다(2026-10 Sahm 0.0, 침체 아님).

M2-4 결정 기록(2026-11-19, 권장안 승인): 채점 기간은 월간 3개월, 예측 대상은 12개 앵커 순위와 상관 부호, 사용자 입력은 CLI, Sahm 결측은 3개월 중 2개월이면 평균, head 해시는 DB 밖에 보관한다.

## 4. M2 이후 상세

### 4.1 전략 갈아타기 (M2 예측, M3 실행)

갈아타기는 "전략 단위의 마켓 타이밍"이다. 그래서 **갈아타기 규칙 자체를 모델로 보고 원장에서 채점한다.**

| 규칙 ID | 방식 |
|---|---|
| `stay_*` | 한 전략을 계속 유지 (비교 기준) |
| `regime_map_v1` | 국면(L3 성장×물가 + 상관 국면)별로 미리 정한 전략 선택 |
| `strategy_momentum_v1` | 직전 12개월 위험조정수익이 가장 높은 전략 선택 (기준선) |
| `human` | 사용자가 다음 분기 우세 전략과 상위·하위 자산군 3개를 예측 |

- **채점:** 다음 63거래일의 샤프·낙폭을 같은 기간 벤치마크와 `stay_*`와 비교한다.
- **비용 반영:** M3에서는 거래비용을 반영한다. 세금은 M4에서 반영한다. 실제 운용은 ISA 계좌와 해외주식 일반 계좌를 함께 쓰므로, 계좌별 과세 방식(해외 계좌의 양도차익 과세, ISA 비과세·분리과세 한도)을 넣어 갈아타기 순효과를 세후로 다시 채점한다.

### 4.2 국면 (M2)

- **L2 경기 4단계:** 규칙 두 가지를 경쟁시킨다. 하나는 INDPRO + Sahm, 다른 하나는 CFNAI-MA3 + Sahm이다. 두 규칙 모두 NBER 침체 날짜와 얼마나 일치하는지를 보조 진단으로 기록한다(2026-11-21 결정: 규칙 채택 기준이 아니며 주 평가는 신호에 따른 포트폴리오 성과·원장 사후 채점·독립 표본 수다).
- **L3 성장×물가:** 성장은 CFNAI, 물가는 CPI 전년비의 수준과 방향으로 4분면을 나눈다.
- **상관 국면:** SPY와 IEF의 36개월 롤링 상관 부호. 다음 분기의 상관 부호를 예측 대상으로 등록한다.
- L1(장기 부채 사이클·MP 단계)은 연 1회 갱신하는 맥락 변수로만 쓴다.

### 4.3 채점과 오차 노트

- **전략 채점:** CAGR, 변동성, 샤프, 소르티노, Calmar, 최대낙폭, 벤치마크 대비 초과수익·추적오차·정보비율
- **예측 채점:** 자산군 순위 IC, 상위 3개와 하위 3개 스프레드, 상관 부호 적중률(Brier score)
- **귀인:** 자산군 배분 효과와 주식 내부 선택 효과(Brinson)
- **오차 노트:** 채점이 끝난 예측마다 "예측 근거 / 실제로 움직인 요인 / 수정 제안"을 기록한다. 수정 제안이 규칙 변경으로 이어지면 ADR과 시도 횟수를 함께 기록한다.
- **판정 가능성 표시:** 리포트에 현재 표본으로 탐지할 수 있는 최소 효과(MDE)를 같이 보여준다.
