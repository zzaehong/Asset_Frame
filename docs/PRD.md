## 1. 제품 한 문장

다양한 자산군으로 만든 여러 배분 전략을 같은 기준으로 비교한다. 거시 국면에 따라 **어떤 전략이 더 나을지**를 사전 등록하고, 결과를 채점한다. 이 과정을 반복하면서 벤치마크보다 수익은 높고 낙폭은 작은 운용을 찾아간다.

## 2. 성공 기준

모든 기준은 **같은 기간의 벤치마크와 비교한 상대 기준**이다. 벤치마크는 S&P 500(SPY 100%)과 60/40(SPY 60% · IEF 40%) 두 가지다.

1. **예측 → 오차 → 수정 루프가 쌓인다.** 원장에 예측, 채점, 오차 노트가 매달 쌓이고, 규칙 수정은 근거와 함께 기록된다. 표본은 앞으로 만들어가는 것이며, 원장이 그 과정 자체를 산출물로 남긴다.
2. **수익:** 운용 전략의 위험조정수익(샤프·Calmar)이 벤치마크보다 높다.
3. **낙폭:** 운용 전략의 최대낙폭이 같은 기간 벤치마크의 최대낙폭보다 작다. 절대 낙폭 한도로 전략을 탈락시키지 않는다. -20%는 개인 감내 수준을 넘었다는 **경고 표시**로만 쓴다.
4. **판단 시간:** 월 1회 실행으로 진단·기록·리포트를 끝낸다.

## 3. 비목표

자동 주문, 실시간 시세, 개별 주식 선택, 뉴스·감성 분석, 다중 사용자, 미국 외 해외 주식(2026-11-18 제외 결정).

## 4. 데이터 원칙 (변경 시 ADR 필요)

1. **공식 원천만 사용한다.** 크롤링과 비공식 금융 라이브러리는 금지한다.
2. **숫자는 결정론적 코드로 계산한다.**
3. **point-in-time:** 가격은 버전 관리하고, 거시 지표는 ALFRED 빈티지와 발표일 기준으로 쓴다.
4. **충돌은 격리한다.**
5. **자동 주문은 없다.**
6. **원장은 추가만 할 수 있다(해시 체인).**
7. **앵커 시계열은 교체하지 않는다.** 이력이 긴 핵심 ETF는 세분 ETF가 편입된 뒤에도 계속 유지한다. 세분 ETF는 앵커를 **대체하지 않고 추가**된다. 이렇게 해야 같은 자산의 장기 기록이 끊기지 않는다.

## 6. 시스템 구조

```
[Data]       Tiingo · KRX · FRED/ALFRED → 원본 보존 → 품질 검사 → SQLite
[Analytics]  수익률·변동성·상관행렬(36개월 롤링)·위험기여도·낙폭·VaR      ← M1
[Strategies] 기준 전략 후보(SAA) 백테스트 · 리밸런싱 규칙 비교             ← M1
[Regime]     L2 경기 4단계(규칙 경쟁) · L3 성장×물가 · 주식-채권 상관 국면 ← M2
[Ledger]     자산군 순위 · 상관 부호 · 다음 분기 우세 전략을 사전 등록     ← M2
[Rotation]   전략 갈아타기 규칙(TAA) — 기준 전략 고정 대비 채점            ← M3
[Execution]  적립금 리밸런싱 · 세금 · 계좌 배치 · 한국 상장 동일 노출 매핑 ← M4
[Report]     월간 HTML → SwiftUI Mac 앱                                  ← M1 / M5
```

## 7. 전략 후보 (M1)

| 전략 ID | 구성 | 역할 |
|---|---|---|
| `bench_spy` | SPY 100% | 벤치마크 |
| `bench_6040` | SPY 60 · IEF 40 | 벤치마크 |
| `inv_vol` | 자산군 앵커를 변동성 역수로 가중 | 위험균등(단순) |
| `erc` | 위험기여도가 같아지도록 가중(상관관계 반영) | 위험균등(정식) |
| `all_weather_approx` | 주식 30 · 장기채 40 · 중기채 15 · 금 7.5 · 원자재 7.5 | 국면 분산 |
| `permanent` | 주식 · 장기채 · 금 · 현금 각 25 | 국면 분산 |
| `equal_weight` | 자산군 앵커 동일가중 | 순진한 기준 |
| `min_variance` | 공분산 기반 최소분산(롱온리, 자산당 상한 설정) | 분산투자기법 |

- 리밸런싱 규칙: 월간, 분기, 밴드(목표 대비 ±5%p) 세 가지를 비교한다.
- 위험 추정 창: 36개월로 하고 민감도 분석을 함께 한다.
- 레버리지는 쓰지 않는다. ISA 계좌에서도 실행할 수 있는 형태로 제한한다.

## 8. 전략 갈아타기 (M2 예측, M3 실행)

갈아타기는 "전략 단위의 마켓 타이밍"이다. 그래서 **갈아타기 규칙 자체를 모델로 보고 원장에서 채점한다.**

| 규칙 ID | 방식 |
|---|---|
| `stay_*` | 한 전략을 계속 유지 (비교 기준) |
| `regime_map_v1` | 국면(L3 성장×물가 + 상관 국면)별로 미리 정한 전략 선택 |
| `strategy_momentum_v1` | 직전 12개월 위험조정수익이 가장 높은 전략 선택 (기준선) |
| `human` | 사용자가 다음 분기 우세 전략과 상위·하위 자산군 3개를 예측 |

- **채점:** 다음 63거래일의 샤프·낙폭을 같은 기간 벤치마크와 `stay_*`와 비교한다.
- **비용 반영:** M3에서는 거래비용을 반영한다. 세금은 M4에서 반영한다. 실제 운용은 ISA 계좌와 해외주식 일반 계좌를 함께 쓰므로, 계좌별 과세 방식(해외 계좌의 양도차익 과세, ISA 비과세·분리과세 한도)을 넣어 갈아타기 순효과를 세후로 다시 채점한다.

## 9. 국면 (M2)

- **L2 경기 4단계:** 규칙 두 가지를 경쟁시킨다. 하나는 INDPRO + Sahm, 다른 하나는 CFNAI-MA3 + Sahm이다. 두 규칙 모두 NBER 침체 날짜와 얼마나 일치하는지를 정확도로 기록한다.
- **L3 성장×물가:** 성장은 CFNAI, 물가는 CPI 전년비의 수준과 방향으로 4분면을 나눈다.
- **상관 국면:** SPY와 IEF의 36개월 롤링 상관 부호. 다음 분기의 상관 부호를 예측 대상으로 등록한다.
- L1(장기 부채 사이클·MP 단계)은 연 1회 갱신하는 맥락 변수로만 쓴다.

## 10. 채점과 오차 노트

- **전략 채점:** CAGR, 변동성, 샤프, 소르티노, Calmar, 최대낙폭, 벤치마크 대비 초과수익·추적오차·정보비율
- **예측 채점:** 자산군 순위 IC, 상위 3개와 하위 3개 스프레드, 상관 부호 적중률(Brier score)
- **귀인:** 자산군 배분 효과와 주식 내부 선택 효과(Brinson)
- **오차 노트:** 채점이 끝난 예측마다 "예측 근거 / 실제로 움직인 요인 / 수정 제안"을 기록한다. 수정 제안이 규칙 변경으로 이어지면 ADR과 시도 횟수를 함께 기록한다.
- **판정 가능성 표시:** 리포트에 현재 표본으로 탐지할 수 있는 최소 효과(MDE)를 같이 보여준다.

## 12. 개념 레지스트리

투자자산운용사 개념은 층을 만들 때 그 층에 필요한 것만 등록한다([docs/concepts/README.md](docs/concepts/README.md)). M1에서는 분산투자기법(평균-분산, 위험기여도, 전략적 자산배분)과 리스크관리(변동성, VaR, 최대낙폭), 투자운용결과분석(샤프, 소르티노, 정보비율)을 다룬다.

## 13. 범위 통제

- 한 작업에서 새 데이터 소스나 새 계층은 하나만 추가한다.
- README에 "구현됨"으로 적는 항목은 테스트로 확인된 것만 허용한다.
- 원장 데이터를 근거로 하지 않은 규칙 변경은 하지 않는다. 변경할 때는 ADR과 시도 횟수를 기록한다.
